DonasOS 1.1.15.18 — Mensagens de pagamento

Base: versão 1.1.15.17 aprovada.

Novidades:
- Texto de pagamento configurável em Configurações.
- Botão para copiar a mensagem do pedido sem incluir a chave PIX.
- Botão separado para copiar somente a chave PIX.
- Mensagem preenche automaticamente cliente, número, valor e forma de pagamento.
- Para cartões, informa pagamento na entrega/retirada.
- Para dinheiro, registra e informa se precisa de troco e para quanto.
