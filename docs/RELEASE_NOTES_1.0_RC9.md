# DonasOS v1.0 RC9 - Assistente de Porções

## Ajustes

- O Assistente de Porções agora mostra a imagem cadastrada de cada ingrediente.
- O Assistente começa recolhido para não atrapalhar o uso diário da tela Estoque.
- Adicionado botão para abrir/fechar o Assistente quando necessário.
- Mantido o SQL de reset da inauguração em `docs/SUPABASE_1.0_RESET_INAUGURACAO.sql`.

## Observação

A função de modo de testes/sandbox fica planejada para depois da inauguração, para evitar risco de misturar dados reais e dados de teste na véspera do uso oficial.
