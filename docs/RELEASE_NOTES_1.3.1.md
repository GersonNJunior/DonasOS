# DonasOS 1.3.1 - Assistente de Porções e Cloudflare

- Corrige textos antigos de Local/offline.
- Adiciona assistente de configuração de porções e unidades no estoque.
- O assistente puxa automaticamente itens de Massa, Molho, Proteína, Complemento e Finalização.
- Permite configurar itens semelhantes com porções diferentes, como mussarela picada e mussarela ralada.
- Mantém Supabase como fonte de persistência.
