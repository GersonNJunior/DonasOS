# DonasOS 1.1.9 — Reservas internas

- Nova opção **Pedido para agora / Reserva** no PDV interno.
- Campos obrigatórios de data e horário para reservas.
- Nova tela **Reservados**, agrupada por dia e ordenada por horário.
- Reservas continuam usando o mesmo fluxo de status, pagamento, estoque e cozinha.
- Compatível com o banco atual: os dados da reserva são sincronizados no campo de observação, sem exigir SQL ou alteração de tabela.
- O cardápio online não foi alterado.
