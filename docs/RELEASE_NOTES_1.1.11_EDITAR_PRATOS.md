# DonasOS 1.1.12

- Cada prato listado no pedido agora pode ser clicado para edição.
- Ao selecionar um prato, todos os ingredientes e quantidades são recarregados.
- O botão muda para “Atualizar este prato”.
- A atualização substitui somente o prato escolhido e mantém os demais.
- O pedido continua na mesma posição da fila durante toda a edição.
